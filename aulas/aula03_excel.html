Aula 03: Planilhas dinâmicas e operações básicas

O Excel se destaca por recalcular automaticamente os resultados quando algum valor muda. Esse recurso torna a planilha muito mais dinâmica e útil.

O que torna a planilha dinâmica

Uma planilha estática contém valores fixos, enquanto uma planilha dinâmica recalcula automaticamente os resultados quando alguma célula muda.

Essa lógica é possível porque o Excel possui um motor de cálculo que atualiza as fórmulas conectadas aos valores alterados.

Como criar fórmulas

Toda fórmula no Excel começa com o sinal de igual. A partir daí, você pode somar, subtrair, multiplicar ou combinar operadores matemáticos.

Exemplos comuns:

  • =A1+B1 para somar;
  • =A1-B1 para subtrair;
  • =A1*B1 para multiplicar;
  • =A1/B1 para dividir.

Ao arrastar uma fórmula para baixo ou para o lado, o Excel ajusta automaticamente as referências, o que facilita a reprodução de cálculos em várias linhas.

Dica: A tecla F4 ajuda a alternar entre referências relativas e absolutas dentro de uma fórmula.
