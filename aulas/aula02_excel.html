Aula 02: Planilha, células e tipos de dados

O Excel funciona como uma grande grade de informações. Para usar bem o programa, é fundamental entender como a planilha é organizada.

Planilha, pasta de trabalho e célula

É comum usar a palavra "planilha" para se referir a tudo dentro do Excel, mas existem três conceitos diferentes escondidos nesse termo:

  • Pasta de trabalho — é o arquivo .xlsx como um todo, o que você salva no computador;
  • Planilha — é cada uma das abas dentro do arquivo, geralmente vistas na parte inferior da tela;
  • Célula — é o menor espaço dentro da planilha, formado pelo cruzamento de uma linha com uma coluna.

Cada célula tem um endereço único, formado pela letra da coluna e o número da linha — como A1, B7 ou D23.

Curiosidade: Uma planilha do Excel tem, atualmente, 1.048.576 linhas e 16.384 colunas.

Por que o tipo de dado importa

Um erro comum de quem está começando é tratar tudo como se fosse a mesma coisa: só "informação digitada na célula". Mas o Excel enxerga tipos de dados diferentes, e essa distinção é o que faz fórmulas funcionarem — ou quebrarem.

Se o Excel entende um número como texto, por exemplo, ele simplesmente não vai conseguir somá-lo. Por isso, reconhecer os tipos de dados é uma das primeiras habilidades que separam quem "mexe no Excel" de quem realmente entende o Excel.

Os principais tipos de dados

  • Texto: Maria, Zé Doca, Produto A;
  • Número: 150, 3,14, -20;
  • Data: 11/07/2026;
  • Hora: 14:30;
  • Moeda: R$ 1.250,00;
  • Percentual: 25%;
  • Lógico: VERDADEIRO / FALSO.

Dica: Se um número aparecer alinhado à esquerda, pode ser um sinal de que o Excel o interpretou como texto.
